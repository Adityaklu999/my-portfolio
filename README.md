# Aditya Reddy — Premium Portfolio

## Run locally
Open `index.html` in a browser.

Everything needed is included in this folder:
- `index.html` — portfolio structure/content
- `style.css` — premium responsive styling
- `script.js` — animations, menu, cursor glow
- `assets/profile.jpeg` — supplied profile photo
- `assets/Aditya_Reddy_Resume.pdf` — supplied resume

## Notes

- Contact links use the email/phone from the supplied resume.
- GitHub and LinkedIn use the profile URLs from the supplied resume.
- No fake project/demo URLs were added.
